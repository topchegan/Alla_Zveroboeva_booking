# CLAUDE.md — паспорт продукта

## 1. Название сервиса
Сервис онлайн-записи «Маникюрный салон Алла Зверобоева».

## 2. Цель и задачи
**Цель:** дать клиентам возможность самостоятельно записаться к мастеру на свободное время, а администратору — управлять услугами, мастерами, расписанием и записями.

**Задачи:**
- показывать только реально свободные слоты с учётом графиков, блокировок и существующих записей;
- исключить двойную запись к одному мастеру на одно время;
- дать клиенту личный кабинет со своими записями, отменой и переносом;
- дать администратору инструменты для ведения справочников, расписания и всех записей.

## 3. Целевая аудитория
- Клиенты салона — люди, которые хотят записаться на маникюр, педикюр, наращивание или услуги для бровей без звонка.
- Администратор салона — ведёт услуги, мастеров, расписание и записи.

## 4. Роли пользователей и матрица прав
Роли: `client`, `admin`. Администратор создаётся начальными данными (seed); стать админом через регистрацию нельзя. Права проверяются на сервере (API), а не только скрытием кнопок.

| Действие | Гость | client | admin |
|---|---|---|---|
| Регистрация и вход | ✅ | — | вход ✅ |
| Просмотр услуг и мастеров | ✅ | ✅ | ✅ |
| Создание записи | ❌ | ✅ (себе) | ❌ (записи создают клиенты) |
| Просмотр записей | ❌ | только свои | все |
| Отмена / перенос записи | ❌ | свои, не позже чем за 24 ч | любые, без ограничения 24 ч (кроме начавшихся и прошедших визитов) |
| Управление услугами и мастерами | ❌ | ❌ | ✅ |
| Управление графиками и блокировками | ❌ | ❌ | ✅ |
| Доступ к /admin | ❌ (→ вход) | ❌ (HTTP 403 «Нет доступа», в т.ч. по прямому адресу) | ✅ |

## 5. Функции клиента
| Функция | Потребность |
|---|---|
| Регистрация и вход по email и паролю | Иметь личный аккаунт для записей |
| Восстановление пароля (экран-заглушка) | Понимать, куда обратиться при потере пароля |
| Выбор услуги (+ опция «Дизайн ногтей») | Выбрать нужную процедуру и узнать цену и длительность |
| Выбор мастера | Записаться к конкретному специалисту |
| Выбор свободного времени | Видеть только реально доступные слоты |
| Подтверждение записи | Быть уверенным, что время закреплено |
| Личный кабинет | Видеть свои записи, их статус и время, включая изменения от администратора |
| Уведомления в кабинете | Узнать, что администратор перенёс (было → стало) или отменил запись: счётчик непрочитанных у «Мои записи», блок уведомлений в кабинете, пометка «Время изменено администратором» в карточке |
| Отмена записи (≥ 24 ч до визита) | Освободить время, если планы изменились |
| Перенос записи (≥ 24 ч до визита) | Сменить время без создания новой записи |

## 6. Функции администратора
| Функция | Потребность |
|---|---|
| Управление услугами (создание, изменение, отключение) и настройками опции «Дизайн ногтей» | Поддерживать актуальный прайс |
| Управление мастерами (создание, изменение, отключение, услуги мастера) | Отражать актуальный состав и специализацию |
| Управление графиками работы мастеров (только вт–сб, в пределах 10:00–20:00) | Задавать рабочее время для расчёта слотов |
| Управление блокировками времени (с предупреждением о пересечении с записями) | Закрывать обеды, личное время, выходные |
| Просмотр всех записей | Видеть загрузку салона |
| Отмена любой записи | Освобождать время по просьбе клиента или салона |
| Перенос любой записи | Менять время, в т.ч. позже чем за 24 ч до визита (но не начавшегося визита) |

## 7. Основные пользовательские сценарии
**Клиент — запись:**
1. Регистрируется (или входит) по email и паролю.
2. Выбирает основную услугу; для ногтевой услуги у подходящего мастера — при желании опцию «Дизайн ногтей» и число ногтей.
3. Выбирает мастера из активных, выполняющих услугу.
4. Выбирает дату (до 30 дней вперёд) и свободный слот (шаг 30 мин).
5. Подтверждает запись — сервер повторно проверяет, что слот свободен.
6. Видит запись в личном кабинете.

**Клиент — отмена / перенос:**
- Не позже чем за 24 ч до визита: отменяет (статус меняется, время освобождается) или переносит на другой свободный слот (меняется время той же записи).
- Позже — только через администратора.

**Администратор:**
- Услуги и мастера: добавляет, редактирует, отключает; назначает мастерам услуги.
- Расписание и блокировки: задаёт рабочие дни и часы, еженедельные блокировки.
- Записи: просматривает все записи (фильтры по дате, мастеру, статусу), отменяет и переносит любые будущие; клиент получает уведомление в личном кабинете (услуга, мастер, для переноса — было → стало) и видит пометку в карточке («Отменена администратором» или «Время изменено администратором» у нового времени той же записи). Свои отмена и перенос клиента уведомлений не создают; уведомления становятся прочитанными, когда клиент открыл кабинет.
- При отключении мастера или услуги с будущими записями и при блокировке поверх записей записи не отменяются автоматически — админ видит предупреждение и решает сам.

## 8. Справочные данные
**Салон:** вт–сб 10:00–20:00, вс и пн — выходные. Часовой пояс — Москва. Только по предварительной записи.

**Услуги:**
| Услуга | Цена | Длительность |
|---|---|---|
| Маникюр с покрытием гель-лаком | 1800 ₽ | 90 мин |
| Маникюр и педикюр | 3200 ₽ | 150 мин |
| Наращивание ногтей | 2800 ₽ | 150 мин |
| Дизайн ногтей (доп. опция) | 300 ₽ за 2 ногтя | 2–4 ногтя: +15 мин; 6–10 ногтей: +30 мин |
| Коррекция и окрашивание бровей | 1200 ₽ | 40 мин |
| Ламинирование бровей | 1800 ₽ | 60 мин |

«Дизайн ногтей» — только доп. опция к ногтевым услугам и только у мастеров, которые его выполняют (сейчас — Анна Ковалева). За визит — одна основная услуга.

**Мастера и графики:**
| Мастер | Услуги | График |
|---|---|---|
| Анна Ковалева | маникюр с покрытием, маникюр и педикюр, наращивание, дизайн ногтей | вт–пт 10:00–18:00 |
| Марина Орлова | коррекция и окрашивание бровей, ламинирование бровей | ср–сб 11:00–20:00 |
| Елена Смирнова | маникюр с покрытием, наращивание, коррекция и окрашивание бровей, ламинирование бровей | вт, чт, сб 10:00–19:00 |

**Блокировки (еженедельно):**
- Анна Ковалева — чт 13:00–14:00, обед.
- Марина Орлова — пт 15:00–17:00, личное время.
- Елена Смирнова — сб весь день, выходной.

**Расчёт слотов:**
- сетка — шаг 30 минут; запись открыта на 30 дней вперёд;
- технический перерыв между записями не нужен;
- запись целиком помещается в рабочее время мастера; слот, который не успевает закончиться до конца смены, не показывается;
- один мастер не обслуживает двух клиентов одновременно;
- учитываются действующие записи и блокировки; длительность = услуга + опция дизайна.

**Правила записи:**
- запись создаётся только на свободный слот;
- нельзя создать две действующие записи к одному мастеру на одно время (проверка в транзакции + ограничение в БД; временного резерва слота нет);
- отменённая запись не удаляется, а меняет статус; время снова свободно;
- перенос меняет время существующей записи, новая не создаётся;
- отключённые мастера и услуги не показываются при создании новых записей, но сохраняются в уже созданных; запись хранит свои цену и длительность (правка услуги их не меняет), а название услуги и имя мастера берутся из справочника (переименование видно и в старых записях);
- график мастера — только в дни и часы работы салона (вт–сб, 10:00–20:00);
- клиент видит только свои записи, администратор — все;
- клиент может отменить или перенести запись не позже чем за 24 ч до визита; позже — только через администратора;
- онлайн-оплаты нет.

## 9. Инструменты и интеграции
- Node.js 22, Express, встроенный `node:sqlite`.
- Фронтенд — HTML/CSS/JS, отдаётся тем же сервером.
- Запуск в GitHub Codespaces.
- Внешних интеграций нет: нет онлайн-оплаты, входа через Яндекс, уведомлений (email/SMS).

## 10. Ограничения первой версии
- Нет онлайн-оплаты.
- Восстановление пароля — только экран-заглушка.
- Нет входа через Яндекс и других внешних провайдеров.
- Уведомления только в личном кабинете, без email/SMS.
- Одна основная услуга за визит.
- Нет временного резерва слота с таймером.
- Нет деплоя — только запуск в Codespaces.

## 11. Риски
| Риск | Мера |
|---|---|
| Двойная запись на одно время | Проверка в транзакции + ограничение в БД; повторная проверка слота при подтверждении и переносе |
| Доступ к чужим записям и админке | Проверка роли и владельца записи на сервере; /admin и admin-API закрыты для client; чужая запись и чужое уведомление по id недоступны (404) |
| Ошибки расчёта слотов | Учитывать графики, блокировки, длительность с опцией, конец смены, часовой пояс Москвы; проверять на справочных данных |
| Хранение паролей | Только хеш с солью, пароли не логируются и не возвращаются в API |
| Персональные данные | Минимум данных, доступ только владельцу и админу; .env и файл БД не попадают в репозиторий |

## 12. Правила работы для ИИ-ассистента
- Стек: Node.js 22, Express, встроенный `node:sqlite` (без внешних пакетов для БД); фронтенд на обычных HTML/CSS/JS, его отдаёт тот же сервер; порт из переменной `PORT`, по умолчанию 3000.
- Изменения структуры БД — только через нумерованные SQL-миграции в `migrations/`, которые применяются автоматически при старте. Актуальная схема описана в `docs/db-schema.md` и обновляется вместе с миграциями.
- Все настройки и секреты — через переменные окружения. В репозитории есть `.env.example` с перечнем переменных без настоящих значений. `.env` и файл базы данных добавлены в `.gitignore` и никогда не коммитятся.
- Интерфейс на русском и адаптивный под мобильный экран.
- Перед изменениями сначала объяснять план.
- Не добавлять функций вне паспорта.
- Если реализация расходится с паспортом — обновить CLAUDE.md, чтобы описание соответствовало сервису.
