# Alla_Zveroboeva_booking

Сервис онлайн-записи «Маникюрный салон Алла Зверобоева». Описание продукта — в [CLAUDE.md](CLAUDE.md).

## Запуск

Нужен Node.js 22.

```bash
npm install
npm start
```

Откройте http://localhost:3000 (порт можно задать переменной `PORT`, см. `.env.example`).

## Страницы

| Адрес | Страница |
|---|---|
| `/` | Главная |
| `/login`, `/register`, `/forgot-password` | Вход, регистрация, восстановление пароля (заглушка) |
| `/booking` | Запись: услуга → мастер → время → подтверждение |
| `/booking/success?id=…` | Запись создана |
| `/cabinet` | Личный кабинет |
| `/cabinet/reschedule?id=…` | Перенос записи |
| `/admin` | Админ-панель: записи |
| `/admin/services`, `/admin/masters`, `/admin/blocks` | Услуги, мастера и графики, блокировки |
| `/403` | Нет доступа |

## Этап 1: тестовые данные

Сейчас нет базы данных и авторизации. Все данные идут через `public/js/api.js`,
который возвращает тестовые данные из `public/js/mock-data.js` и хранит изменения
в `localStorage` браузера (раз в сутки тестовые данные создаются заново, потому что
даты записей считаются от сегодняшнего дня). Сбросить данные — очистить данные сайта в браузере.

Шапка зависит от раздела: гостевая на главной и страницах входа, клиентская
на `/booking` и `/cabinet`, администраторская на `/admin`.
